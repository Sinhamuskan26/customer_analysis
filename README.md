# Retail Customer Purchase & Sales Analysis

## 📌 Project Overview

This project analyzes customer purchasing behavior and sales patterns using a retail customer dataset.

The analysis was performed using **Python and MySQL** to understand customer spending, product performance, discounts, subscriptions, customer segments, categories, and seasonal sales.

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* MySQL
* SQL
* VS Code

## 📊 Dataset

The dataset contains **3,900 customer purchase records** and includes information such as:

* Customer demographics
* Products purchased
* Product categories
* Purchase amount
* Location
* Season
* Review ratings
* Subscription status
* Shipping type
* Discounts and promo codes
* Previous purchases
* Payment method
* Purchase frequency

## 🔧 Data Cleaning

The following preprocessing steps were performed using Python:

* Checked data types and missing values
* Handled missing review ratings using category-level median values
* Standardized column names
* Removed unnecessary spaces from column names and values
* Converted column names to lowercase
* Renamed `purchase_amount_(usd)` to `purchase_amount`

## ⚙️ Feature Engineering

### Age Groups

Customers were divided into four age groups using quartiles:

* Young Adult
* Adult
* Middle Aged
* Senior Citizen

### Purchase Frequency

Purchase-frequency categories were converted into approximate days:

* Weekly → 7 days
* Fortnightly → 14 days
* Bi-Weekly → 14 days
* Monthly → 30 days
* Every 3 Months → 90 days
* Quarterly → 91 days
* Annually → 365 days

## 🗄️ SQL Analysis

The cleaned dataset was loaded into MySQL and analyzed using SQL.

Key business questions included:

1. What is the total revenue generated by male and female customers?
2. Which customers used discounts but still purchased above the average purchase amount?
3. Which products have the highest average review ratings?
4. How does average purchase amount differ between Standard and Express shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which products have the highest percentage of discounted purchases?
7. How can customers be segmented based on previous purchases?
8. What are the top 3 products within each category?
9. What is the subscription distribution among highly repeat customers?
10. What is the revenue contribution of each age group?
11. Which locations have the highest number of orders?
12. What is the average purchase amount by category?
13. What is the median purchase amount by category?
14. How does sales and revenue vary by season?

## 🔍 Key Finding

Male customers generated higher total revenue in the analyzed dataset:

* **Male:** $157,890
* **Female:** $75,191

This indicates a significant difference in total revenue contribution between the two groups and provides an opportunity for further analysis of customer count, purchase frequency, and average purchase value.
